- Contato realizado (sobre Leads): 75% / 85%
- Qualificação MQL (sobre Contato): 45% / 70%
- Agendamento (sobre Qualificado): 60% / 78%
- Comparecimento (sobre Agendado): 58% / 68%
- Proposta apresentada (sobre Comparecimento): 85% / 92%
- Fechamento/Venda (sobre Proposta): 28% / 42%
- Ticket médio: Meta R$3.800, Google R$4.600

O que construir:

Um único arquivo HTML autocontido (HTML, CSS e JavaScript puro, sem nenhuma biblioteca externa, sem CDN), funcionando como um app de dashboard, com:

1. KPIs no topo, em cards: investimento total, leads totais, CPL médio, vendas fechadas, receita total, ROAS geral.
2. Funil completo por etapa, calculado a partir das taxas acima, comparando Meta x Google x Total (tabela ou barras em CSS puro, sem biblioteca de gráfico).
3. Diagnóstico crítico: aponte as 3 a 5 maiores quebras do funil, a causa provável de cada uma e uma recomendação prática para cada quebra.
4. Plano de ação com 4 a 6 itens priorizados (ação, hipótese, impacto esperado).

Regras:
- Calcule tudo em JavaScript a partir dos dados brutos acima. Não invente número nenhum.
- Não use nenhuma biblioteca externa nem CDN, pra funcionar offline em qualquer navegador.
- Visual limpo: fundo branco, azul-marinho e verde-água como cores principais, cards com cantos arredondados.
- Entregue só o artefato em HTML. Não repita os dados nem explique o raciocínio no chat, pra economizar mensagens.
- Não peça mais informações. Os dados acima são tudo que você precisa pra construir o app completo.
